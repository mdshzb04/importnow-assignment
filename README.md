# ImportNow Assignment

A React and TypeScript implementation of the [ImportNow reference website](https://importnow-concept.vercel.app/), built as a frontend assignment. The project includes an interactive Earth hero, a scroll-driven shipment journey, home-page sections, and a nine-article blog.

## Stack

- React 19, TypeScript and Vite
- React Router for listing and article routes
- Three.js for the Earth and shipment scenes
- CSS and Tailwind CSS, with Lucide icons

## Run locally

Use Node.js 22.18 or later and npm.

```sh
git clone https://github.com/mdshzb04/importnow-assignment.git
cd importnow-assignment
npm ci
npm run dev
```

Open **http://127.0.0.1:5173**. If that port is occupied, use the URL printed by Vite.

No environment variables, API keys or `.env` file are required. Fonts and scene textures are included in `public/`.

## Build and checks

```sh
npm run build
npm run lint
node scripts/check-blog.mjs
node scripts/check-whatsapp.mjs
node scripts/check-scenes.mjs
```

The production build is written to `dist/`. Run `npm run preview` to preview it locally.

The Node checks cover blog filtering, search, pagination and article data; WhatsApp quote URL generation; and shipment timeline and globe route logic. They do not verify visual appearance or WebGL rendering.

## Features

- Responsive home-page sections and navigation
- Textured Earth with trade routes and city markers
- Scroll-driven shipping and delivery sequence
- Blog categories, search, pagination and article pages
- WhatsApp quote form with prefilled messages
- Reduced-motion handling and a fallback when 3D scenes cannot load

Routes are `/`, `/blog` and `/blog/:slug`. The quote form opens WhatsApp; it does not submit to a backend. `vercel.json` supplies the SPA rewrite for direct navigation and refreshes on Vercel.

## Project structure

```text
src/
  components/   Shared layout, blog and home components
  data/         Article content and site data
  hooks/        Metadata and reveal behaviour
  lib/          Blog, contact and motion helpers
  pages/        Home, blog, article and not-found pages
  scenes/       Three.js scenes, lifecycle and timeline logic
  sections/     Home-page sections
  styles/       Application styles
public/         Local fonts, images and textures
scripts/        Logic checks and optional texture preparation
```

## Asset credits

- **Earth textures:** [Solar System Scope](https://www.solarsystemscope.com/textures/), licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Day, night, clouds, normal and specular maps are included. Modifications include TIFF-to-PNG conversion, a cloud alpha layer and 1024 × 512 mobile copies.
- **Water normal map:** an original procedural seamless texture generated by `scripts/prepare-scene-assets.py`.
- **Fonts:** Inter by Rasmus Andersson and Sora by Sora Project Authors, distributed under the SIL Open Font License 1.1. Licence texts are included in `public/fonts/`.
- Dependencies retain their respective licences. Website branding and reference content belong to their respective owners; this repository is an assignment implementation.

To regenerate the textures, use Python 3 with Pillow installed and run `python scripts/prepare-scene-assets.py`. This optional step downloads the Earth source maps and generates the water normal. It is unnecessary for a normal checkout because the prepared assets are included.
